  <h3>Civil Network Development Organization</h3>

  <p>Here at Civil Network, we make open-source proxies and web browser ports for use in educational environments.</p>

  <h4><i>Projects</i>:</h4>
  <div>
    <p><b><a href="//github.com/civilnetwork-dev/Civil">Civil</a> is a browser-based web proxy and entertainment website for students.</b></p>
    <p><b><a href="//github.com/civilnetwork-dev/MagniJev-wasm">MagniJev-wasm</a> lets you run decision models such as Laya in the browser.</b></p>
    <p><b><a href="//github.com/civilnetwork-dev/Filter-Sources">Filter-Sources</a> is a project that diagnoses when a web filter vendor responds specifically to Civil.</b></p>
    <p><b><a href="//github.com/civilnetwork-dev/Tilesturn">Tilesturn</a> is an open-source WebAssembly-based Cloudflare Turnstile solver for use on modern web proxies.</b></p>
    <p><b><a href="//github.com/civilnetwork-dev/Whiskey">Whiskey</a> is a modified fork of Stellite Games' Gex ecosystem adapted specifically for Civil's needs.</b></p>
  </div>
